# Harvest Sow

Sow seeds around a valley field to harvest crops before the crows do, sell at the village market, spend coins to grow the valley and hire a helper.

- Play the prototype: open `prototype/dist/index.html`
- Docs: `docs/00-handoff.md` (start here), `docs/01-design-bible.md`, `docs/02-no-mac-ios-pipeline.md`
- Build: `node prototype/build.js` · Levels: `node prototype/tools/gen-levels.js`
